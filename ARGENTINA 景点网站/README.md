# 🇦🇷 阿根廷景点指南

一个展示阿根廷25个最佳景点的静态网站，基于 HTML + CSS + JavaScript 开发，可通过 GitHub Pages 免费托管。

## ✨ 功能特性
- 📑 景点目录快速导航
- 📱 完全响应式设计，支持手机/平板/电脑
- 🏷️ 景点卡片展示：名称、介绍、地址、电话、营业时间
- ❓ 常见问题折叠面板
- ⬆️ 平滑滚动体验

## 🚀 本地预览
直接用浏览器打开 `index.html` 即可预览网站。

## 📦 部署到 GitHub Pages
1. 将所有文件上传到你的 GitHub 仓库
2. 进入仓库 → Settings → Pages
3. Source: Deploy from a branch
4. Branch: main / root → Save
5. 访问：`https://你的用户名.github.io/argentina-attractions/`

## 📄 许可证
仅供学习交流使用，内容基于 restgeo.com 整理。
